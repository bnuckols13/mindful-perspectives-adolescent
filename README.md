# Willful, Willing, Wise — Mindful Perspectives (Adolescent)

A single-page teen DBT skills resource on Marsha Linehan's Wise Mind paired with the Willingness vs. Willfulness distinction, framed as three brain modes (Willful, Willing, Wise) the body knows before the mouth does.

The page is hosted at: `https://bnuckols13.github.io/mindful-perspectives-adolescent/`

Built for adolescents in eating-disorder recovery, gambling-adjacent presentations, and general distress work. Voice tuned to land at 14–17 without pandering; clinical content sourced from Linehan (2015) Mindfulness Handout 3 and Distress Tolerance Handouts 13–14, with the adolescent gloss from Rathus &amp; Miller (2015).

A single self-contained HTML file with inline styles. No tracking, no analytics, no JavaScript.
